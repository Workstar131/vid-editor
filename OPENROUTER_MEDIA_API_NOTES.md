# OpenRouter media API notes

Research checked 2026-10-21.

- Image generation: https://openrouter.ai/docs/guides/overview/multimodal/image-generation — `POST /api/v1/images`, model discovery at `/api/v1/images/models`; request supports prompt, aspect_ratio, resolution/quality/output_format and optional `input_references`; outputs include base64 image bytes and media type. Public model discovery returned `openai/gpt-image-2`, `openai/gpt-image-2.5-sunburst`, `google/gemini-3-pro-image`, `google/gemini-nano-banana-2.1`, `bytedance-seed/seedream-5-0-flash`.
- Video generation: https://openrouter.ai/docs/guides/overview/multimodal/video-generation — asynchronous `POST /api/v1/videos`, poll `GET /api/v1/videos/{jobId}`, download `GET /api/v1/videos/{jobId}/content`; supports `frame_images` entries using `{type:'image_url', image_url:{url}, frame_type:'first_frame'|'last_frame'}`. Signed output URLs may be returned. Public model discovery returned `bytedance/seedance-2.5`, `google/veo-3.1`, `alibaba/wan-2.7`, `minimax/hailuo-3`, and others.
- TTS: https://openrouter.ai/docs/guides/overview/multimodal/tts — `POST /api/v1/audio/speech`, returns raw audio bytes; voice/model support is model/provider-dependent. Public `output_modalities=speech` discovery returned models including `google/gemini-3.8-flash-tts` and `mistralai/voxtral-mini-tts-3-0`.
- STT: https://openrouter.ai/docs/guides/overview/multimodal/stt — `POST /api/v1/audio/transcriptions`, accepts OpenAI-compatible multipart upload; response JSON can include segments and optional word timestamps (`verbose_json`, `timestamp_granularities[]=word`). Public `output_modalities=transcription` discovery returned `openai/whisper-large-v3`, `openai/whisper-1`, and others.
- Overview: https://openrouter.ai/docs/guides/overview/multimodal/overview — OpenRouter has dedicated image, video-generation, TTS, and STT routes; actual model capabilities vary and must be checked. These services still have provider/model billing and platform restrictions; 'no Puter dependency' cannot mean unlimited cost or guaranteed model availability.
